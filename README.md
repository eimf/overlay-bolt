# Overlay Notes

A transparent drawing overlay for iPad and iPhone. Draw, annotate, and highlight on top of anything — a lesson, a video, a document — without the app imposing its own background.

- Fully transparent canvas with optional geometric guides (lines, squared, dots)
- Pen, highlighter, and eraser tools with configurable color, width, and opacity
- Fullscreen and floating (draggable) overlay modes
- Cloud save is opt-in and can be turned on or off at any time

See `docs/` for full product documentation.
