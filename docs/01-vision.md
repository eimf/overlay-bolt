# Vision

**Overlay Notes** is a transparent drawing overlay for iPad / iPhone. The user
wants to sketch *on top of* whatever they are looking at — a lesson, a video, a
document in another window — without the app imposing its own background.

## What it is

- A **semi-transparent** canvas that floats above content.
- A **minimal** toolset: pen, highlighter, eraser, undo, clear.
- An optional **geometric guide**: lines, squared, or dots.
- An optional **cloud save** so sketches can be recalled later.

## What it is NOT

- Not a notebook with page backgrounds. **No photo mockups** (no lesson images,
  no math paper, no code screenshots).
- Not a full-fledged drawing app (no layers, no brushes library).
- Not mandatory cloud — the user must be able to turn persistence **off**.

## Guiding principles

1. The canvas should disappear until you draw on it. Transparency is the
   default; anything opaque is opt-in.
2. Every piece of chrome must be dismissible so the stroke is the hero.
3. Persistence is a **feature**, not a requirement. Off by default.
